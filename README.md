# Dungeon Adventure

A 3D dungeon adventure you play in the browser. Pick a hero, wake the four pillars, beat the skeletons and escape through the golden door.

**Play:** https://zainasuw.github.io/dungeon-adventure/

## How to play

| Key | What it does |
| --- | --- |
| W A S D or arrow keys | Walk |
| F or click | Attack (it aims for you; hold to keep swinging) |
| G or right-click | Special move |
| Space | Dodge |
| Q | Hero power |
| H | Drink a potion |
| Esc | Pause |

Walk up to the glowing altar to take the pillar, defeat the skeletons it wakes, then follow the golden arrow to the door. Collect all four pillars to win. Easy mode is made for kids.

## Heroes

Warrior, Priestess, Thief and Doctor, each with their own special ability.

## Run it locally

```bash
npm install
npm run dev
```
